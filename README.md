# CropImage
Обрезает картинку курсором в заданной области. Простейший кропер для подготовки небольших датасетов для обучения нейросетей.

Рекомендую использовать PyCharm. Версия Python 3.7
Зависимости: pip install Pillow tkinterdnd2

Программа, которая позволяет пользователю кадрировать изображение с графическим интерфейсом, пользователь может перетащить изображение в окно программы. После загрузки изображение отображается в окне. Пользователь выделяет рамку на изображении для кадрирования. По нажатию кнопки "Save" (или Ctrl+S) программа сохраняет кадрированное изображение с пометкой "_crop". При прокрутке колесика мыши изображение будет приближаться или отдаляться.

## Управление

- ЛКМ — выделить область кропа. Рамка ходит рывками по сетке кратности (см. «Кратность кропа»).
- ПКМ по рамке — перенести выделение, не меняя его размера. ПКМ по пустому месту — панорама.
- Средняя кнопка мыши — панорама. Стрелки — тонкий сдвиг (со Shift — крупный).
- Колесо — зум под курсором (мельче, чем раньше; с Ctrl — быстрее). `+` / `-` — зум вокруг центра окна, `0` — вписать изображение в окно, «Zoom 1:1» — пиксель в пиксель, `Esc` — сбросить выделение. Зум хранится как «экранных пикселей на пиксель изображения», поэтому 1:1 остаётся 1:1 после изменения размера окна, поворота и смены масштаба; пределы зума заданы и от этой величины, и от вписывания в окно, так что «вписать» и «1:1» достижимы всегда (на маленьком изображении зум может выйти за пределы «относительного» диапазона — это намеренно). Быстрая прокрутка колеса считается от уже запланированного шага: десять щелчков дают десять шагов зума, а не один.
- Ctrl+S / кнопка Save — сохранить. Ctrl+O — открыть файл.
- В окно можно бросить файл (или несколько — берётся первый); ориентация из EXIF применяется при загрузке, так что фото с телефона поворачиваются автоматически.
- Рамка кропа не исчезает при зуме и при изменении размера окна: выделение хранится в пикселях рабочего изображения.
- При изменении размера окна вид не «телепортируется»: в центре остаётся тот кусок картинки, который был виден (даже если центр окна смотрел мимо изображения), а простое перемещение окна окна без изменения его размера вообще не вызывает перерисовку. На экране всегда остаётся не меньше трети видимой области изображения.

## Сохранение

- Файл пишется с тем же расширением, что у исходника (кроп — `name_crop.jpg`/`name_crop.png`, маска — всегда `name_mask.png`). Сохранение — Ctrl+S или кнопка Save.
- Для JPEG режим цвета сохраняется: RGB, L и CMYK (полиграфический CMYK не перекрашивается в RGB молча). Если режим для выбранного формата не подходит, программа сохраняет кроп в RGB и сообщает об этом в строке состояния.
- Стороны кропа, кратные 2, не гарантируются сами по себе — если включена кратность, они кратны ей; если стороны всё же не кратны 2, при сохранении появляется предупреждение «(внимание: не кратно 2)».

## Меню «Опции»

- **Фиксировать квадрат** — рамка всегда квадратная.
- **Фиксировать разрешение** + **Выбрать разрешение** — рамка заданного размера: 1536x1536, 1024x1024, 768x768, 640x640, 512x512. Если выбранное разрешение больше рабочего изображения, кроп берётся по границам изображения (об этом сообщает подпись рамки и строка состояния); если включена ещё и кратность, сторона дополнительно округляется вниз до сетки — например, 1536 на изображении 2000x1500 с кратностью 64 даёт ровно 1536x1472. При смене разрешения уже выделенная рамка перестраивается под новый размер (верхний левый угол по возможности сохраняется), так же она перестраивается при смене кратности и после смены масштаба исходника — размер рамки остаётся ровно заявленным. Если включены оба пункта («Фиксировать квадрат» и «Фиксировать разрешение»), берётся сторона фиксированного разрешения, ограниченная изображением и сеткой, то есть рамка остаётся квадратной и кратной одновременно.
- **Кратность кропа** — 1 (свободно), 2, 4, 8, 16, 32, 64. Стороны прямоугольника получаются кратными выбранному значению, прямоугольник «прыгает» по этой сетке, а файл сохраняется ровно по выделенной области. Нужно для Image-to-Image моделей, которым важны разрешения, кратные 2: если стороны всё же не кратны 2, программа предупреждает в подписи рамки и в строке состояния. Если выбранная кратность больше меньшей стороны изображения, шаг автоматически становится 1 (свободно), чтобы кроп нельзя было убить одним «прыжком»; об этом сообщает строка состояния.
- **Масштаб исходника** — Оригинал (без масштабирования), либо **по большей стороне** / **по меньшей стороне**: 1024, 1536, 1920, 3072. Пропорции сохраняются: например, картинка 6000x8000 с «по большей стороне 1536» даёт рабочее изображение 1152x1536 (k = 1536 / 8000 = 0.192), и дальше зум и кроп работают уже с ним. Исходник в полном размере остаётся в памяти, поэтому масштаб можно менять туда-обратно без потери качества. Увеличение ограничено (не больше ×8 по стороне и не больше ~30 млн пикселей), иначе узкая картинка вроде 64x4000 при «по меньшей стороне 3072» раздувалась бы до гигантских размеров; при ограничении программа пишет фактический коэффициент.
- **Zoom reset (вписать в окно)**, **Zoom 1:1 (пиксель в пиксель)** — 1:1 работает и на больших изображениях: рисуется только видимая область, а не вся картинка.
- **Повернуть 90° вправо (по часовой)** и **Повернуть 90° влево (против часовой)** — поворот рабочего изображения; выделенная рамка поворачивается вместе с ним, а не сбрасывается.
- **Сохранять новые версии в разные файлы** — файлы вида `name_crop_01.png`, `name_crop_02.png`, …
- **Сохранять в отдельную папку** + **Выбрать папку для сохранения…** — кропы (и маски) пишутся в выбранный каталог, а не рядом с оригиналом.
- **Сохранять только маску кропа (ЧБ)** — вместо кропа сохраняется чёрное изображение рабочего разрешения (того, с которым вы работаете, с учётом масштаба) с белым прямоугольником выделенной области. Всегда сохраняется как PNG (`name_mask_01.png`).

## Строка состояния

Внизу окна показывается: размер рабочего изображения и как оно получилось из исходника (сторона, цель, коэффициент k), текущий зум, размер кропа с отметкой кратности, режим сохранения (кроп или маска), папка сохранения и версии. Там же появляется путь к последнему сохранённому файлу.
